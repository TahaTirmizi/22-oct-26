| Section             | Questions / tasks | Time    | Score   |

## 8-week plan

About 1.5–2 hours on weekdays, plus a longer weekend session.

| Week | Focus | Checkpoint |
| ---- | ----- | ---------- |
| 1 | Diagnostic test. Learn the format. Quant: arithmetic and number properties. Start vocab (30 words/day). | Diagnostic scores logged |
| 2 | Quant: algebra and word problems. Verbal: Text Completion strategy. | 2 timed quant sets |
| 3 | Quant: geometry and coordinate geometry. Verbal: Sentence Equivalence. | Vocab review: 300+ words |
| 4 | Quant: data interpretation and statistics. Verbal: Reading Comprehension. Write 1 Issue essay. | Essay self-scored against ETS rubric |
| 5 | Mixed timed sets. Go through the error log and redo missed questions. | Error log reviewed |
| 6 | POWERPREP test #2 under real conditions. Spend 2 days reviewing it. | Scores logged |
| 7 | Target weak areas from test #2. 2 more essays. | Weak-area sets done |
| 8 | Light review, 1 paid practice test if needed, rest the day before. | Ready |
